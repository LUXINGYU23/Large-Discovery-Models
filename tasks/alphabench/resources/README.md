# AlphaBench T3 resources

`operators.json` records the full operator signatures from the pinned Qlib and Assay guides.
`data_sources.json` pins acquisition URLs, source commits, periods and archive hashes.
`evidence/` contains compact source inspections and measured development checks.
`qualification_evidence.json` records registration gates without implying that the
complete T3 method/market matrix has passed. Raw market data and complete traces
remain outside Git under `/mnt/data1/`.
