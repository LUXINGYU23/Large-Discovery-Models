- 开发副本已增加距离重建后有限性与占据一致性检查：发生符号漂移则按原有非法提案路径拒绝，不重新二值化、不放宽约束。远程相关回归 **7 项通过**，包含真实浮点漂移复现和原有亚体素累积测试；尚未完成修订版的全容器与负载验收。

## 固定目标与公平预算

- 主指标：独立确认测量损失 `L/(1+L)`，先在父体内平均，再对父体等权平均；失败为 1。IoU 仅作辅助重建指标，不参与训练排序或验证选型。
- 三种方法：完整 LDM（AST/Qwen 等权融合、框架既有 1+3 研究策略）、修复后的 MCMC、修复后的 ACQ。发现种子均为 42、43、3407。
- 各组初始化 + 20 轮 × 16 个收费源码，总上限 321。接口拒绝占用预算，不能补成 321 个成功结果；记录完整轮数与真实耗用。
- 求解上限统一为 120 秒、2 CPU、4 GiB；非活动区、可活动体积 2%–65%、最多 4 连通体完全相同。该先验不使用每个隐藏真值的体积或家族标签。
- LDM 沿用官方 DeepSeek `deepseek-flash`（V4.1 Flash）、low；使用服务器上的 Qwen3 缓存。
- 全局最多 80 作业：8 个接口专用、72 个求解/评分；每进程最多 16。基线初始化后按原序每批 16 个预留并行，结果按原序发布。私有服务并发运行，保留同源互斥与封存屏障。

旧 r1 已停止，不能与新目标、新数据、新约束的曲线拼接。旧序列化重复源和已收费成本保留在旧账本，新版本不得伪装成旧运行的续跑。
