# 铜矿几何反演 v2：约束、独立数据与公平评估方案

日期：2026-10-24。状态：**方案复核版；已有开发实现及pilot证据，任务入口已切换v2，正式科学契约、隔离验收和独立正式实验尚未完成。** 本文定义验收要求，不把开发实现等同于已验证的科学结论。

依据：[v1 技术报告](copper-technical-report/report.md)、现有任务接口与评分源码、最终冻结算法的18次复验及12次事后缺测诊断。本方案替代 v1 的科学评估契约，不覆盖旧结果，不把新旧损失放在同一排行榜。

## 0. 要解决的问题与成功标准

v1 已证实的问题不是“loss没有算出来”，而是**算得正确的目标仍允许不合理答案**：

- 非活动区仅作为诊断，钻孔/露头最佳解分别有7.73% / 2.23%的正值体积落入其中。
- 四接触点专用程序和固定数组在当前案例上能赢；改变孔布局时可能退化成回退算法。
- 两个案例共享同一矿体背景、钻孔、网格及初始模型，不能作为两个独立泛化样本。
- 接触点同时进入正类分类项；距离未按测量误差无量纲化，数据量影响损失尺度。
- 没有隐藏真值指标和独立测试集；“三个执行seed稳定”被误读成算法发现或地质不确定性稳定。
- 多配置搜索择优的发现成本没有体现在单个最终求解器的120秒预算里。

**v2 的核心交付：一个冻结程序，在从未参与发现和选型的独立地质体上，满足公开可行域约束，并在相同资源下恢复更准确的几何。**主评价使用隐藏真值几何，观测拟合和正则项同时报告。仍称“地质单元几何反演”，不声称已实现铜品位或重磁物性反演。

必须通过的门槛：

1. 任何方法的最终输出均不能包含一个已确认禁入区正值体素。
2. train / validation / test 不共享母体地质模型、派生模型或观测生成谱系。
3. 每种方法只提交一个冻结程序/规则，处理整个测试套件；禁止测试时按case事后挑胜者。
4. LDM和MCMC使用相同可行域、公开观测目标、先验、输入信息和求解预算。
5. 同时展示合法率、隐藏几何准确度、观测预测误差、成本和失败；不能靠排除失败样本提高均值。

## 1. 范围和实施原则

### 1.1 两级真实度

**第一阶段：有真值的、地质结构更丰富的受控合成任务。**这能检验泛化与几何准确度，但只能称合成地质反演，不能把增加随机噪声描述成真实矿区验证。

**第二阶段：独立来源的真实矿区或公开地质模型。**必须有明确许可、坐标/单位、钻孔轨迹、地形和解释来源；按矿区分组。真实数据没有完整真值时，只评隐藏整孔/测点、地质专家盲评和约束一致性，不伪造体积IoU。若尚未取得合格数据，就明确停留在第一阶段，不用同一示例的旋转、重采样冒充外部验证。

后续如加入重力/磁法，另立 v3 物性与前向算子契约，并以 SimPEG 等成熟库实施；本次不同时重写为多物理反演。

### 1.2 复用框架

复用当前 Candidate、Campaign、研究树、GP/代码编码、任务注册、容器执行器、只读接口检查、独立评分器及预算账本。新增的只是**任务的地质契约、数据套件和suite聚合**，不再实现一套agent循环、调度器或通用实验平台。

保留 v1 文档、源码快照、容器摘要和证据作为历史归档。活动任务切换到 `problem_schema_v2` / `geometry_v2` / `objective_v2`，新目录新campaign；不添加猜测版本的fallback或旧数据兼容分支。

## 2. 先审核“非活动区”是什么意思

不能直接把所有 `~active_mask` 都解释成空气。v2 输入明确区分：

| 字段 | 意义 | 是否允许矿体 |
|---|---|---|
| `domain_mask` | 评估的物理区域 | 域外无输出、无体积计分 |
| `forbidden_mask` | 经来源确认的空气、空洞或明确不含该地质单元的区域 | **绝不允许** |
| 域内其余区域 | 可行岩体区域，包括没有采样的地方 | 允许，由数据与先验推断 |
| `observations.mask` | 哪些位置有测量 | 缺测不等于负类 |
| `open_boundary_faces` | 哪些模型外边界允许目标体延伸 | 按公开地质设定决定 |

v1 `ind_active` 进入新数据集前，核对上游定义、UBC轴顺序、地形和实物坐标；至少检查三个物理剖面及若干已知点。语义无法确认则只留作旧示例诊断，不作为 v2 硬约束真值。

合成数据的禁入区由**独立的地形/空气模型**产生，不通过“真矿体的补集”生成。否则会把答案编码进可行域。钻孔负标签也不能沿整个未测空间扩展成禁入区。

## 3. 输出与几何规范化：让约束可核验

### 3.1 公开接口

保留函数形态：

```python
def solve(problem: dict, budget: dict, seed: int) -> np.ndarray:
    # 返回与公开网格同shape的有限float场，正值代表目标单元
    ...
```

`problem` 新增明确的mask、单位、测量不确定度和公开先验；不传 split 标签、地质体真值、生成参数、母体ID、随机种子或带答案语义的case名称。`case_id` 仅为无语义请求ID。

### 3.2 主任务采用体素占据几何

v2主任务明确是有限分辨率的几何重建：输出先验证，再固定转换为 `M = (f > 0)`；所有损失、距离和几何指标都基于同一个 `M`。不保留 v1 通过逐点幅值改变亚体素零面位置的自由度，也不声称获得了亚网格精度。

统一流程：

1. 检查文件、shape、dtype、finite、体积上限及所有硬约束；`f==0`按外部处理。
2. 禁入区有任何 `M=True` → `invalid_geometry`，**不静默裁剪**。
3. 标准距离用固定的±1占据场、公开spacing重建；截断域、开放边界和物理地表的处理写入 `geometry_v2` 摘要。
4. 全空/全满集合必须有明确定义：在允许无矿体的case中，采用预先规定的有限距离截断值，并按空集合IoU/F1规则评分，不能依赖skfmm偶发报错。禁止以有无矿体的隐藏真值决定是否合法。

空集合约定：预测和真值均空，IoU=1；仅一者为空，IoU=0。主发布集可先只含存在矿体的观测，但接口测试仍覆盖空集合。

所有方法可调用同一个公开 `canonicalize/feasibility/data_objective` 实现，也可自行实现更快近似；正式分数只认独立评分器。MCMC的提案先经过同一可行性判断；非法提案拒绝并计入实际运行成本，不由评分器替它修矿体。

**取舍：**这个设计减少连续场幅值对离散评分的影响，但会引入网格量化与分段常数目标，可能降低连续局部优化器的效率；这一取舍对所有方法一致公开。因此必须做不同spacing和分辨率收敛检查，并用物理距离容差解释几何误差。连续亚体素任务将来另行版本化，不能与占据任务混排。

## 4. 矿体合理性：普适硬约束与条件先验分开

### 4.1 普适硬约束

- 输入不可写、输出有限、维度/坐标一致、无不允许的外部访问。
- 域外无有效预测；已确认禁入区正值数必须为零。
- 若公开契约声明某外边界为封闭，目标体不得进入其固定物理厚度的禁入边界带；开放边界允许截断，不按“触边=错”处理。
- 任何额外的几何必需条件都必须来自公开任务信息，不能由隐藏真值临时推导。

### 4.2 条件先验

| 指标 | 默认处理 | 可升级为硬约束的条件 |
|---|---|---|
| 总体积 | 报告；有可信粗范围时使用软区间惩罚 | 独立证据提供保守物理上下界 |
| 连通分量 | 报告各分量体积与最大分量占比 | 已知且公开的单体/多体假设 |
| 小碎片 | 基于公开最小可分辨尺度的软惩罚 | 工程任务明确禁止该尺度碎片 |
| 界面粗糙度/面积 | 弱正则和诊断 | 不默认硬切；断层和薄脉可有复杂表面 |
| 边界截断 | 按开放/封闭边界分开报告 | 仅封闭边界带禁止正值 |
| 方向/层序 | 有独立结构测量时加入软约束 | 经地质定义确认的严格顺序关系 |

默认不能强制“仅一个连通分量”“所有矿体闭合”“越小越好”或“越光滑越真实”。多矿体、断层位移和薄脉是正式数据的一部分，不能被规则先验排除。

初期共享正则：在可行域内部的邻接异号面上计算物理面积 `A_internal`，使用 `R_area=A_internal/V_domain^(2/3)`；地表和允许的开放边界不当作额外粗糙度。这个轴向体素面积存在方向偏差，必须测试旋转敏感性；它是弱先验，不是真值准确度。

体积区间惩罚采用无量纲 hinge：`R_volume=[max(0,Vlo−V)/Vdomain]^2+[max(0,V−Vhi)/Vdomain]^2`。没有合法公开体积区间时该项关闭，不能从本case真值自动生成窄区间。

## 5. 统一 objective_v2 与外层科学评价

### 5.1 内层：所有求解器看到的同一公开目标

`J_public = L_binary + L_contact + λ_area R_area + λ_volume R_volume + λ_fragment R_fragment`。

- 二值标签只包含0/1；接触标签0.5**不再进入正类分类项**。
- 二值概率用 `p = ε + (1−2ε) sigmoid(φ/τ)`，最小化稳定Bernoulli NLL；τ为公开的物理过渡/定位尺度，ε为公开的标签错误模型。干净标签可取ε=0，数值实现使用稳定log形式。
- 接触点采用 `Huber(φ/σ_contact)`；接触位置不确定度具有物理单位。
- 先按孔或独立观测组取平均，再按预声明的数据模态权重聚合，避免密集露头或同孔大量重复采样自动支配目标。
- 正则只能使用公开信息，不读取真值。默认权重原型为数据模态等权、`λ_area=0.02`，无额外先验时 `λ_volume=λ_fragment=0`；这些只是**开发集校准起点**，不得直接当成物理定律。
- 权重和噪声参数在公开开发pilot上做单位、网格和退化行为测试后冻结。最终套件创建前记录公式、权重、容差和实现摘要；两个竞争方法使用完全相同值，不分别为LDM或MCMC挑评分器。

这能去掉已知漏洞，但不能保证仅凭数据拟合得到真矿体。必须同时引入隐藏几何评价。

### 5.2 外层：算法发现与报告的统一指标

主指标为**以母体地质体等权的、计入失败的宏平均IoU**。失败/超时/非法输出按IoU=0计入该case的原定分母；同时单独公布硬约束合法率。不能只在成功样本上排榜。

辅助指标：

- 表面F1：容差为 `max(公开定位误差尺度, 1个体素对角线)`，两种单位都写入报告。
- 对称平均表面距离、HD95、相对体积误差；域截断面不当作内部真实接触面。
- 接触RMSE、按孔/模态分组的二值预测误差和NLL。
- 非活动区占比、分量数、碎片体积、触边面、公共目标各项。
- solver墙钟、CPU秒、峰值内存、失败数；所有内部计数说明口径。

真实无真值case不计算IoU，使用预封存的独立测量预测成绩，另表报告。

### 5.3 训练反馈与内层目标不能混淆

训练集真值留在trusted scorer；每个候选在训练suite上运行完后，可向研究agent返回训练宏平均IoU、合法率和误差摘要，作为算法设计反馈。MCMC配置调参获得相同训练反馈机会。候选solver运行时始终只读公开观测；不能调用隐藏真值oracle。

内层MCMC接受/优化依据 `J_public`，不能借用真值指导单次反演。它的外层超参数选型可根据训练真值指标进行，与LDM的外层源码选择对应。测试时所有程序及超参数已冻结。

## 6. 真正独立的训练、验证和测试case

### 6.1 分割单位是母体地质模型，不是文件或采样点

生成不可公开的 `parent_geology_id` 与完整派生谱系。一个母体的旋转、镜像、坐标平移、网格重采样、换钻孔、加噪声、增删露头、裁剪patch，以及从同一解释模型派生的几何，全都属于同一group，只能在同一split。

数据生成前划分父级种子空间和模板谱系；生成后做SHA、规范化体积/表面描述和相似体检索，排查近重复。仅换随机seed不充分；共享母体参数、固定四孔布局、复用答案派生初始模型都视为泄漏风险。

### 6.2 数据规模与发布层次

| 阶段 | train母体 | validation母体 | test-ID母体 | test-OOD母体 | 用途 |
|---|---:|---:|---:|---:|---|
| 工程pilot | 8 | 4 | 4 | 4 | 验证约束、隔离、成本；结果不作最终结论 |
| 第一版正式suite | 24 | 8 | 16 | 8 | 主实验 |

每个母体生成**两种观测包**：稀疏钻孔；钻孔＋露头。二者留在同一split，评分先在母体内平均，再在母体间平均。正式suite因此为48个训练、16个验证、32个ID测试和16个OOD测试观测包。pilot与正式suite母体完全分离；用于调试过的pilot全部视为开发数据。

### 6.3 地质与观测变化

ID训练、验证和测试采用相同的预声明分布，但使用独立母体，覆盖：

1. 弯曲接触面/层状体；
2. 闭合透镜体或侵入体；
3. 倾斜脉状体及多个不连通体；
4. 带断层位移的复合结构。

训练/验证/ID测试各类分别为6/2/4个母体。存在多种几何族，不能让“单值高度面”覆盖全部问题。

观测参数按独立随机流生成：钻孔数在3～12之间、接触数随真实穿越变化（含0/1/3/4/多次接触）；加入斜孔、成簇孔、覆盖不足、缺失孔段、多个穿越区间；露头由真实地表与单元相交生成，而不是把完整顶面标签全部公开。区分定位误差和标签错误，保留干净/有噪声分层。

网格使用不同shape、非单位和各向异性spacing；物理尺寸与地质尺度独立于数组尺寸。初始场用训练前固定、只依赖公开数据或统一几何先验的构造器生成，不能是真值平滑版、真值膨胀版或带其中心/体积信息的模型。

地质生成优先复用GemPy的结构单元、层序和断层关系，采用独立参数化模型生成/光栅化真值；不从待评估LDM代码或MCMC后验中产生答案。另有解析几何只用于单元测试。地质质量检查人员看真值但不看方法名称和结果；剔除条件预先写入，不能事后删除方法不擅长的case。

### 6.4 OOD测试单独标记

8个母体用于受控分布外测试：4个来自未用于ID的结构组合/独立生成配方，4个来自明确的观测覆盖或分辨率偏移。尽可能一次改变一个因素，结果分组报告。来自另一生成器的数据也仍是合成数据，不称真实矿区。

不能从“在已知生成器上换seed”推出跨生成器泛化。若没有能力建立独立配方或外部数据，此项标为未实现，不用ID样本充数。

开发阶段现采用两类具体偏移验证管线：未用于ID的“断层＋闭合透镜”结构组合；钻孔孔口和露头采样集中在独立随机选择的四分之一宽度窗口，地质类型仍来自ID。后一组孔数、标签噪声机制与ID一致，孔轨迹可倾斜穿出窗口。窗口位置不查询真值。两类分别报告，不称跨生成器或真实矿区泛化；正式配方须在pilot审核后冻结，再用新母体重新生成。

### 6.5 防止先验把答案泄漏给算法

- 先采样地质设定与公开先验，再在该设定内生成真实体；不先生成体，再给出恰好包住它的窄体积范围。
- 公开先验类别必须是现实可获得的信息，并对所有方法相同。隐藏的“真结构类型”不作为solver输入。
- 禁入区、拓扑/体积先验和初始模型都做信息来源审计；与母体ID、真值参数、文件顺序相关的元数据从公开包中移除。

## 7. 验证与测试的隔离协议

### 7.1 访问矩阵

| 参与方 | 训练观测 | 训练真值 | 验证/测试输入 | 验证/测试真值及谱系 |
|---|---|---|---|---|
| 研究agent / 工具shell | 允许 | 不挂载，读训练反馈 | 不允许 | 不允许 |
| 训练solver容器 | 当前case公开输入 | 不允许 | 不允许 | 不允许 |
| 封存评估solver | 不需访问历史 | 不允许 | 仅当前case公开输入 | 不允许 |
| 独立scorer | 当前case及需用的真值 | 允许 | 允许 | 允许 |
| 人工结果分析 | 按阶段开放 | 按协议 | 测试冻结后 | 测试结束后 |

隐藏集存放于独立评估账户/服务，不能仅靠文件名叫`private`或在同一共享目录chmod后假定安全。研究agent不获得宿主机SSH、Docker socket、隐藏集下载工具或评估服务任意命令权限。允许训练调用的工具做数据集allowlist；命令输出和异常信息不泄漏隐藏路径/参数。

### 7.2 固定选型流程

1. 每次发现campaign仅使用训练集。**同一程序在所有训练case运行**，禁止为每个case保存不同的最终算法。
2. 训练结束按预声明规则提出最多3个封存候选，记录完整源码、依赖、参数和选择顺序。所有候选先冻结，再运行验证。
3. 验证仅执行一次批次；每个候选获得一个按母体聚合的成绩，研究agent不收到逐case模型/残差。按宏IoU、合法率和预声明tie-break选出一个候选。
4. 验证后不再改代码、参数或生成新候选；任何修改都属于新一代研究，需要新的保留验证/测试设计。
5. 测试一次性运行固定算法/固定seed表；包括错误与超时。结果揭盲后，旧测试集降级为已见数据，后续开发不能继续把它称独立测试。

MCMC及确定性基线遵循同样的3个候选上限、验证反馈限制和冻结规则。测试期算法可以根据**当前公开测量**自适应选择内部策略，但选择规则必须预先固化，不接受测试指标反馈。

MCMC/ACQ开发调参采用预注册的低维Sobol参数搜索（默认配置先评估），不称代码BO。温度对数范围`[0.001,10]`，步长`[0.5,4]`最小网格间距，相关尺度倍率`[0.125,2]`，初始化在公开观测最近邻与无真值信息的随机场之间选择。ACQ额外搜索batch∈{2,4,8}、warmup∈{3,4,8}、beta∈[0,2]。每种方法各自最多321个完整训练套件反馈；接口拒绝照常占位。范围须在开发校准结束后固定，禁止根据测试表现修改。

选型排序现明确为：宏IoU降序，合法率降序，平均求解墙钟升序，源码SHA256字典序。冻结文件同时锁定候选列表、科学实现、镜像摘要、验证/测试manifest及其内容摘要、预算和排序规则。状态依次为`frozen → selected → tested`；完成后重复调用只读取已有结果，不能追加候选、换源码或重置测试。开发实现不等于正式隐藏服务，后者仍须单独验收访问隔离。

## 8. 公平预算：两个层次分别保证

### 8.1 主结果：冻结算法求解预算完全相同

每个case、每个seed统一：

- 120秒候选执行硬上限、2 CPU、4 GiB、64 PID；同机器类别、同锁定镜像、同并发策略，启动前满足资源余量。
- 时间覆盖候选导入、初始化及所有子进程求解；独立评分器单独计时、固定相同上限，不让候选持有其凭证。
- seeds固定为47/48/49，按方法与case交错运行；三种子用于执行稳定性，不能当三个独立case。
- 同公开输入、初始场、可行域、先验、目标公式、库版本和输出后处理。
- 超时/非法输出/耗尽资源按失败计分，没有按方法单独宽限或免费补种子。
- 如做30/60/120秒曲线，提前声明三档、所有方法全跑，不能挑有利档位。

主公平口径是资源，不宣称内部oracle调用完全相同。LDM可能实现自己的近似目标；无法可靠数全所有内部计算。若需要严格等oracle次数，必须设独立的“只能通过计费oracle求值”受限任务，不能与自由算法设计主任务混用。

### 8.2 算法发现/调参额度相同

第一版正式suite，每个方法每次发现重复：

- **321个完整训练suite评估槽位**，对应最多20轮×16候选＋初始算法；每个槽位评估48个训练观测包，seed固定为47。
- 因而最多 **15,408次训练solver运行**，每次120秒/2CPU/4GiB。顺序运行的solver墙钟上限总和为513.6小时，CPU上限总和1,027.2 CPU小时；并发缩短等待，不增加计算额度。
- LDM仅使用AST/Qwen等权融合表征，独占其321个槽位；不再启动AST-only或Qwen-only消融，不附加其他表征搜索额度。
- MCMC用相同槽位调温度、提案尺度/相关长度、初始化和分阶段计划；可采用现有的固定网格/随机/BO调参器，算法族与搜索范围先冻结。确定性基线也获得同样上限，未用完如实报告。
- 每个候选必须跑同一训练suite，不采用选择性case采样或临时剔除困难case。完整suite结果才能进入代理模型，避免不同batch分数不可比。
- 接口失败消耗候选槽位；实际执行成本另记，不用省下的case运行数兑换额外候选。缓存命中不增加新科学反馈额度，恢复重放不重复扣同一逻辑评估。

验证额度：最多3个冻结候选×16个验证观测包×1个固定seed；所有方法相同。测试额度：1个冻结程序×48个测试观测包×3seed；所有方法相同。

LDM额外的LLM token/API、研究工具运行、GPU编码与GP费用**必须另记**。不能把“同训练评分槽位”说成总成本相等。主结论只声明冻结求解预算公平和反馈额度公平；要声称端到端发现更便宜，另做预注册的总计算/货币成本曲线，并给经典调参法同等总成本机会。

### 8.3 运行计划的最小可行规模

先在独立pilot跑：8个训练母体×2观测包、5个候选suite槽位、1个发现seed，验证/测试各固定一次；目标是验证约束和隔离，不发布胜负。

正式实验使用3个**发现seed**重复整套训练→验证→测试；每个冻结算法再用3个执行seed。统计以母体为样本单位，观测变体和执行seed在母体内先聚合；用按母体成组的配对bootstrap区间，不把144个执行作业当144个独立地质体。各方法都按这一重复结构运行。

## 9. 公平且有解释力的基线

必须包含：

1. 原论文MCMC接入统一 v2 约束与目标，标为 **MCMC-v2适配**，不再声称逐字原配置复现。
2. 预注册调参后的MCMC；与默认版并列，避免拿未调好提案的链作唯一对手。
3. package ACQ版本；确保预热能在预算内结束，公布实际采集决策数。
4. 数据驱动确定性基线：标签距离变换＋局部优化；接触面RBF/IDW＋正则；适用范围不足时按固定规则回退并计成本。
5. LDM：单个跨case冻结算法。主结果不再按表征分成三个不同“方法”，本次仅使用AST与Qwen embedding等权融合表征，不运行AST-only或Qwen-only分支。

全部基线使用同一 `J_public`、可行域及可调用的公共库。允许原始初始化与数据驱动初始化作为MCMC调参选项，不能只给LDM强初值。两者都只返回预算内最好的合法体，用独立评分器最终打分。

最小值优化与后验采样分开。若后续比较不确定性，需要另设正确采样分布、有效样本量、覆盖率和校准任务；当前MCMC的best-so-far只作为优化基线。

## 10. 需要增加的测试与防漏洞检查

### 10.1 固定公开接口测试

- 接触点数0/1/3/4/多点，斜孔、多次穿越、无露头、缺失孔段；防止“四接触点才能工作”。
- 非单位spacing、各向异性网格、原点平移、C/F内存顺序；物理坐标不变的存储变换必须保持结果含义。
- 禁入区正值、非有限输出、shape错误、全空集合、封闭/开放边界、允许多体的合法输出。
- 空观测组和无接触组不产生NaN；0.5标签不进入二值项；重复观测和单位缩放按规定不改变评分权重。

### 10.2 可信评分器测试

- 同一个模型用LDM和MCMC路径提交，规范化几何、可行性、公共损失及隐藏指标必须一致。
- 修改输出幅值但保留符号，v2占据几何和评分必须相同；禁入区域一个正体素也判invalid。
- 体积/面积使用spacing及物理单位；空集合和触边指标确定；地表不被误当成额外界面复杂度。
- 真值、公开先验、初始模型分别验证来源；真值不参与公开问题构造器的隐式派生。
- 无网络、候选不能改输入/测试/评分器；结果只从受信作业收据读取，不能信候选自报。

### 10.3 恢复与预算测试

- 在提案生成、接口检查、选择、求解、评分、持久化各阶段注入中断。
- 以稳定的case/suite/source/seed/phase身份建立幂等收据；序列化消息使用确定性规范化，避免字典顺序改变输入digest。
- 区分逻辑科学反馈、实际执行尝试、真实资源成本：已提交回放不重复消耗逻辑槽位，真实重试成本不消失；协议拒绝未产生科学反馈也不能伪造新反馈。
- v1的“恢复失败额外4个turn导致第20轮没预算”必须有回归用例，不通过篡改历史账本或提高上限解决。

隐藏集不是用来频繁调试接口的；所有故障注入使用公开fixtures或pilot。

## 12. 分阶段落地与退出条件

### P0：地质语义和开发契约

审计旧mask语义；明确v2 schema、占据几何、约束矩阵、度量和数据源许可，创建仅供开发的pilot母体。用解析球/斜平面/双体/开放体检查物理坐标。产物：机器可读开发contract与测试预期，最终科学契约在P3校准完成后冻结。**不先跑LDM。**

### P1：最小受约束端到端环境

先让一个固定距离变换程序和一个MCMC-v2适配器，通过相同只读接口和scorer在pilot跑通。构造旧式无限延展平面和禁入区正体素攻击样例，确认非法输出不能成为冠军。同时确认合法多体/开放体不会被一刀切拒绝。

### P2：独立数据与隔离封存

扩充pilot母体、质量检查、谱系去重；验证访问矩阵与数据工具allowlist，演练隔离封存。pilot验证和测试一经用于调试即降级开发集。本阶段不创建正式测试集，避免后续修改契约时根据其表现调整设计。

### P3：预算与基线pilot

按5个候选suite槽位试跑，检查运行时、内存、恢复幂等以及公共目标/隐藏几何指标是否矛盾。所有约束与权重修改在此结束，随后冻结最终科学契约。再按预注册生成规则创建全新的正式suite，签名封存manifest和秘密种子；验证/测试内容不向研究agent暴露，不得沿用不匹配版本或用正式测试表现校准契约。

### P4：正式跨case算法发现

冻结协议后，以相同训练评估槽位运行LDM与基线调参；3个发现seed。训练suite聚合参与BO；每种方法最多3个验证候选，选出一个跨case程序。

### P5：一次性独立测试与报告

测试ID/OOD分开，所有失败进入分母；绘制配对几何质量、成本曲线与3D盲样本。报告必须包含约束合法率和泛化差距，不只展示最优case。保留测试审计日志；揭盲后不得继续在这一测试集迭代并宣称独立。

所有实现调试、数据生成、求解及测试在授权远程服务器执行；本地用于代码与文档。新代码/环境与活动输出置于H20 `/Aidata/shared/ldm/`，归档置于 `/mnt/cephfs/xingyu/ldm/archive/`。不得将隐藏集放在研究agent可访问的共享工作目录。

## 13. 暂不做出的承诺

- 在取得独立真实矿区前，不承诺真实矿体恢复效果。

- 不能保证LDM在更严格环境下仍领先；保留它输给MCMC或简单确定性基线的可能。
- 不用三次执行的低方差替代独立地质体、独立算法发现重复或后验不确定性。
- 不声称LLM/GPU成本与经典方法完全等价；总成本优势必须另证。

## 16. 本次复核补充：正式运行前必须关闭的漏洞

### 16.1 数值定义不能制造新的取巧空间

已有开发校准记录显示，轴向体素面积对球体约高估51%，斜面也存在方向偏差。因此正式版默认将 `λ_area` 设为0，面积暂作明确标注的轴向诊断；如需启用，必须在开发集比较成熟库的物理表面估计、旋转误差和薄体行为，冻结估计器及权重后再生成正式数据。不得把0.02直接继承为已校准值，也不能根据哪种正则使LDM获胜来选择。

采用占据场意味着接触误差存在网格量化下限。测量噪声与离散误差分别记录；有效接触尺度须覆盖经解析几何校准的离散误差，禁止令σ任意趋零来制造巨大分数差。尺度公式、网格范围和容差在公开校准集冻结，对所有方法一致。

占据任务允许算法自行平滑或投影，但这属于候选求解时间；受信评分器不修补非法结果。MCMC的投影提案若改变转移分布，只能称优化适配器，不能把链样本解释为有效地质后验。

### 16.2 独立case与隐藏测量是两层隔离

除母体分组外，每个正式母体预先生成一组不传给solver的确认观测：整孔、空间块露头，且与公开观测使用独立噪声流。禁止随机拆同孔邻近点充当独立测量。其误差作为辅助泛化指标，在验证/测试阶段汇总；不得参与 `J_public` 或事后挑算法。合成确认观测仍来自同一地质模型，只证明该母体上的预测能力，不能冒充外部矿区证据。

生成器参数、真值、谱系、确认观测和质量审计放在私有包；公开包仅包含现实可获得的观测、地形、坐标、误差和先验。观测采样规划可以模拟实际调查策略，但不得为保证某方法容易拟合而查询真值挑孔。保证矿体存在或限制最小体积等筛选条件必须预注册，报告拒收率及因此改变的任务分布。

### 16.3 失败、重试和成本使用统一账本

| 事件 | 科学额度 | 成绩与后续处理 |
|---|---|---|
| 候选接口失败、超时、非法几何 | 消耗该候选槽位 | 失败计入固定分母；不得免费换源码 |
| 可信设施断线、评分器读取错误 | 保留原逻辑评估身份 | 暂停并审计后原样重试；额外真实成本保留 |
| 已完成源码/数据/种子/契约完全相同的重放 | 不新增反馈额度 | 核验收据后复用结果 |
| 科学契约、依赖镜像或数据变化 | 禁止沿用旧身份 | 开新实验，旧结果保留 |
